# One Star, Written in Sap

One line, 1-279 characters: a one-star review written in tree sap.

Entry: `One star: the maple tree dripped sap on my car, my laptop, and my sandwich, and then had the nerve to look beautiful doing it.`

Run: `python3 main.py` (writes the line to `/output/entry.txt`).
